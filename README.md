# FastBox Mystery Delivery System

## Project Description

This project simulates a logistics delivery system for FastBox.

The system:
- Reads JSON test case files
- Assigns packages to the nearest delivery agent
- Calculates delivery distances using Euclidean distance
- Generates delivery performance reports
- Finds the most efficient delivery agent

---

## Features

- JSON parsing
- Euclidean distance calculation
- Nearest-agent package assignment
- Delivery simulation
- Report generation
- Multiple test case support

---

## Technologies Used

- Python 3
- JSON
